# Task 6 - Working Natural-Language Grid Assistant

## Objective

The objective of this task is to develop a working natural-language grid assistant that allows users to ask questions about grid telemetry data using simple natural-language queries.

## Project Description

The Grid Assistant processes user questions and retrieves useful information from the grid data. It provides understandable responses about power consumption, voltage, current, frequency, and grid status.

## Features

- Natural-language query interface
- Grid telemetry data analysis
- Power consumption analysis
- Average power calculation
- Highest power consumption detection
- Lowest power consumption detection
- Voltage analysis
- Current analysis
- Frequency analysis
- Grid status information
- Streamlit-based user interface
